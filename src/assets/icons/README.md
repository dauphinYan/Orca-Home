# 技能图标来源

- `codex.svg`：[asvg 的 Codex 图标](https://asvg.app/icons/codex)，下载自 https://asvg.app/assets/svg/codex/codex-symbol-color.svg 。
- `opencode.svg`、`opencode-dark.svg`：[OpenCode 官方品牌素材](https://opencode.ai/brand)，分别使用 [浅色主题方形图标](https://github.com/anomalyco/opencode/blob/dev/packages/console/app/src/asset/brand/opencode-logo-light-square.svg) 和 [深色主题方形图标](https://github.com/anomalyco/opencode/blob/dev/packages/console/app/src/asset/brand/opencode-logo-dark-square.svg)。

以上 SVG 保留下载原稿，页面通过统一的尺寸和 `object-fit: contain` 等比显示。
