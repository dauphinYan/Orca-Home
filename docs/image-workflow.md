# 图片处理流程

1. 将 PNG/JPG 图片放进 `src/assets/` 或 `public/`，正常添加页面引用。
2. `npm run dev` 启动时自动处理已有图片，运行期间新增、替换图片或添加引用也会自动处理。
3. `npm run build` 构建前自动补齐转换，页面引用改为同目录的 `.webp`。

原图保留。优先无损 WebP，保留原尺寸及透明度；若无损版本比原图更大，尝试质量 90、85、80 的有损 WebP。不会统一强制小于 100KB，以免缩小截图或损害文字清晰度。SVG 和现有 WebP 保持原样。

结果缓存位于 `.astro/image-conversion.json`。原图未变且 WebP 存在时跳过压缩；替换原图或删除 WebP 后自动重新生成。无法解码的文件会提示并跳过，替换文件后重试。

博客正文中的相对图片沿用独立的处理流程，构建时输出为 WebP，并按现有策略控制在 100KiB 以内。

需要手动执行时运行 `npm run images:webp`。开发服务未运行时，保存图片不会触发处理，下次开发启动或构建时自动处理。
